## 安装

在**云崽根目录**执行，三个源任选一个（内容完全一样，推荐国内的 gitcode 或 gitee）

```bash
git clone --depth=1 https://gitcode.com/ccxhan/GloryOfKings-Plugin.git ./plugins/GloryOfKings-Plugin/
```

```bash
git clone --depth=1 https://gitee.com/longhengmu/GloryOfKings-Plugin.git ./plugins/GloryOfKings-Plugin/
```

```bash
git clone --depth=1 https://github.com/cchanlan/GloryOfKings-Plugin.git ./plugins/GloryOfKings-Plugin/
```

```bash
cd ./plugins/GloryOfKings-Plugin && pnpm install
```
然后重启云崽即可。

#### 营地隐私开关（**只能私聊发**）

把营地 App「设置 → 隐私」那 16 项搬到指令上：战绩、在线状态、皮肤、观战、粉丝关注访客……
改的是**你自己当前选中的那个营地号**（`#切换营地` 换号）。

| 指令 | 说明 |
| --- | --- |
| `#隐私帮助` `#隐私设置` `#隐私状态` `#隐私列表` | 出图：16 项各自能按哪几类人设置、带编号；图最上面一行是**战绩的实际效果** |
| `#隐私隐藏 <编号>` | 把那一项对所有人藏起来，如 `#隐私隐藏 1` |
| `#隐私公开 <编号>` | 把那一项放开给所有人 |
| `#隐私隐藏 <编号> <档位名>` | 只改一档，如 `#隐私隐藏 1 陌生人`、`#隐私隐藏 5 游戏上线提醒`（档位名照图上的标签写） |
| `#隐藏我的战绩` / `#公开我的战绩` | 一条顶战绩那 4 项（我的比赛 / 比赛详情 / 赛季表现 / 精彩时刻），共 14 档 |

> **改完要等半分钟左右才生效**，别反复发 —— 营地对写请求一律先回成功，生效是异步的。
> 反复发容易撞营地的频控，命中一次这个号会被静默 12 小时。
>
> **哪些项是真的管用**（图上标了「已实测有效」的才算，2026-10-14 逐项挂号验证过：
> 藏起来之后拿别的号去查，看是不是真的读不到了）：
>
> | 项 | 实测结果 |
> | --- | --- |
> | 1 我的比赛 / 2 我的比赛详情 / 3 赛季表现 / 10 英雄、常用英雄 | ✅ **真起作用**（藏起来之后别人查会被服务端挡掉） |
> | 5 在线状态、7 关注、8 访客、11 皮肤、12 铭文、14 星会员等级标识、15 王者日历 | ❌ **营地不管这项设置** —— 设置写得进去（日历那项连写都写不进），但别人照样查得到（不是「关了就开不回来」，是这开关本来就不拦数据） |
> | 4 精彩时刻、6 粉丝、9 点赞、13 观战、16 星足迹卡片 | ❓ **验不了** —— 营地没有（或没找到）「查别人这项」的接口；观战还要求双方是营地好友。设置发得出去、App 里应该会变，但这边无法确认 |
>
> **图上只列能用的那九项**（无效的七项直接不显示）—— 摆着只会让人以为能用。
> 编号是营地自己的，所以图上会**跳号**（缺 5、7、8、11、12、14、15）。真发了会被明确告知原因。
> 图上项名带**绿勾**的是挂号验证过的（藏起来之后拿别的号真查不到），没勾的是验不了的。
>
> **图上只列「能改什么」，不画每一档的开关** —— 营地读取隐私状态的那个接口**读回来的值是假的**
> （实测：别人已经看不到战绩了，它还在说「全部联系人可查看」）。所以图上唯一能就地验证的
> 就是最上面那行战绩效果（拿另一个号实地查出来的）。
>
> **你自己永远看得到自己** —— 营地有「自我豁免」，藏起来之后你自己查还是全部战绩，
> 别以为没生效。要验证就看 `#隐私帮助` 最上面那一行。
>
> **「公开」这个方向需要号上绑着王者角色**（营地只认带角色的那条写入通道）。
> 没绑角色的号藏得了、放不开，只能去营地 App 里改。

> **做完 ≠ 领到**：营地的任务做完只是「完成」，那 25 枚营地币要再点一次「领取」才到账 ——
> 所以会出现「每日前往游戏专区签到(1/1)」后面还挂着「领取」按钮、币却没进账的情况。
> 现在 `#王者签到` 和每日自动签到都会**顺手把做完没领的奖励一起领了**（包括今天已经签过的号），
> 领到多少会写在签到图和私聊里。
>
> 「浏览资讯」「点赞」「分享」这几条也会**顺手做掉**（各 25 营地币）：
> 浏览和点赞要真的去读一篇资讯、点一个赞；分享则只上报一个状态、**不会真的发出去**。
> ⚠️ 点赞是拿你的号**真去点别人的内容**，不想让机器人这么做，就在锅巴「营地签到」里
> 把「签到后顺手做福利任务」关掉（关掉后就只查、只领）。「关注作者」要自己去关注人，不做。

登录态「**用则续命、闲置才死**」，插件每天自动保活，一般不用管；QQ 号失效会自动重登，微信号只能重新扫码。想手动催一次：`#营地续期`（请主人发）。

> 签到用的是**你自己**扫码登录的那个营地号（`#营地观战` 同一套账号），
> 所以要先登录才能签；奖励发在账号上，一个号签一次就够。

### 观战大神

> 不用先加好友：从营地公开的高端局池里随机开 **10 路**直播（排位 5 + 巅峰 5，一边不够就用另一边补满）。

| 指令 | 说明 |
| --- | --- |
| `#观战大神` | 随机开 10 路，直接发链接（用池子里的全局号，**发指令的人不用先登录**，也不用手动加好友） |
| `#观战大神 <分路>` | 只看某个分路：`对抗路` `打野` `中路` `发育路` `游走` |
| `#观战大神 在播` | 看现在有哪几路在跑（和 `#营地观战 在播` 是同一批房间） |
| `#观战大神 停` / `停 <编号>` / `停 全部` | 停自己开的那几路 / 停指定一路 / 全停 |

⚠️ 巅峰赛每天 **12:00** 才开，那之前池子里只有排位 —— 指令照样开 10 路，只是全是排位。

观战要**另跑一个后端进程**（取流和录像）。两条路任选一条 ——

**用别人部署好的**（本机什么都不用装）：

```
#营地观战连接 <地址>              # 对方公网那个地址，通常带 8899 端口
```

⚠️ 2026-10-06 起服务端在**单端口模式**下，公网 8899 同时受理播放页和开播/好友名单，
不再需要让对方专门开第二扇窗。如果对方的服务端还是老版本拆端口形态
（8899 只放直播页、8898 在本机），会提示让对方更新。

**自己部署一套**（机器上得有 ffmpeg）：

```
#营地观战接入 <地址> <令牌>      # 地址和令牌进群 972915804 找主人要
#营地观战部署 / #营地观战服务     # 更新代码 / 看进程、ffmpeg、对外地址配好没
```

⚠️ 这两条别混：`接入` 要的是**分发服务**的地址（拿来下代码），`连接` 要的是**观战服务本身**的地址。填错了只会得到一句 `not_found`。

装好 ffmpeg 但部署仍提示「没找到」时：终端执行 `ffmpeg -version`，有版本号就说明只是插件没找到它，去锅巴「服务端接入」把「ffmpeg 路径」填成完整路径（Windows 形如 `D:\ffmpeg\bin\ffmpeg.exe`），再发一次 `#营地观战部署`。

自己部署时还要把**直播间对外地址**填成外网能访问的（域名或公网 IP）并放行 `8899` 端口，不然群友点开是白屏。

> 端口（2026-10-06 起）：`8899` 是**唯一公网入口**（播放页/直播流/聊天 + 开播/停止/好友名单全量），服务端默认在 `GOK_WATCH_SINGLE_PORT=1` 单端口模式下把工作面合并到这里；`127.0.0.1:8898` 保留为**本机回环备用**（不对外开放）。录像删除 `/rec DELETE` 中间档：本机永远可删；公网无口令时不开放，配 `GOK_WATCH_TOKEN` 后带口令可删。可用 `GOK_WATCH_PORT` / `GOK_WATCH_CTRL_PORT`（和对应 `*_HOST`）覆盖，`GOK_WATCH_MAX_ROOMS` 限制同时在播路数（默认 16）。

### 营地消息

营地好友发来的消息会**转到你的 QQ 私信**（文字和图片都会转），你可以直接回（仅私聊）。

单独看这块的帮助图：`#营地消息帮助`。

| 指令 | 说明 |
| --- | --- |
| **引用那条推送回一句** / `#营地回复 <营地号> <内容>` | 直接回复对方 / 不用引用也行，指定用哪个号回 |
| `#营地好友` / `#营地私聊 <编号> <内容>` | 看在游戏里的好友（图上有编号，10 分钟内有效）/ 按编号给 TA 发消息 |
| `#营地消息` | 看服务状态、哪些号在线、还有多少条待处理 |
| `#营地消息开` `#营地消息开启` `#营地消息打开` `#营地消息收` | 让自己名下的营地号开始收消息（扫过的号默认只用来查询，要收得自己开） |
| `#营地消息关` `#营地消息关闭` `#营地消息停止` `#营地消息不收` | 让自己名下的营地号不再收消息 |
| `#营地消息连接 <地址>` | 用别人部署好的消息服务：只填地址，本机什么都不用装（地址找部署方要） |
| `#营地消息接入 <地址> <令牌>` | 自己部署一套，地址令牌进群 972915804 找主人要（和观战共用） |
| `#营地消息部署` / `#营地消息服务` / `#营地消息同步` `#营地消息重连` | 更新代码 / 看状态 / 按开关重连账号 |

每个营地号的收发**只推给它的归属人**（扫码登录时记下，可在锅巴「账号列表」改「归属 QQ」，没有归属人的号一律不推）；只推真人好友消息，直播流推送和公众号一律不推。对方发图片时会原图转过来（一张消息推一张，最多 9 张）。

⚠️ **收消息是一份独立名单**，跟查询/推送轮询用的账号池是两回事 —— 扫进来的全局账号默认**只拿来轮询查数据**，不挂长连接收消息。要收的号发一句 `#营地消息开` 加进来，也可以在锅巴侧边栏「营地消息」页面点着开关，改完几秒生效、不用重启。

💤 **名单空着的时候插件不会去连服务端**：一个号都没开（或还没接入营地消息服务）时，后台一次请求都不发、日志也不会被「拉取失败」刷屏，所以你看到这一块安安静静是正常的。哪天发 `#营地消息开` 或去锅巴勾一个号，几秒内就自动开始收，不用重启。服务端连不上时会自动退避重试（几秒一次逐步拉长到一分钟一次），拉通一次立刻恢复正常。


单独看这两块的帮助图：`#战绩推送帮助` / `#群战绩报告帮助`。

战绩推送和上下线提醒两个开关互相独立，只在打完新的一局后触发，不会重复推；报告读的是本地战绩归档，不额外刷营地接口。

**开局提醒和开播提示是同一条**：开了上下线提醒的人，一局打完满 N 分钟（默认 3 分钟，见 `#王者设置`）时，群里收到的是**一条**合并提示——开头是「〈名字〉 已经开局 N 分钟了 · 进入了排位赛」，下面接着英雄场次胜率和「要不要开一路观战？发 #营地开播」。以前这两件事各发一条、连着刷两屏，现在并成一条了。看不了的对局（模式不支持观战 / 对方藏了战绩 / 不是全局账号好友）不会发开播提示，但仍有一条纯开局提醒，所以「谁开打了」永远不会漏。

**退出群之后会怎样**：订阅时记的那几个群，人退出去之后插件不会再往那个群推你的战绩。退掉一个群只摘掉那一个，别的群照旧；推送群一个不剩时整条订阅自动停掉（`#关闭在线状态` 那条隐身标记例外，它跟群无关，会留着）。重新进群再发一次订阅即可恢复。

### 营地ID 共享（可选的跨机器人功能）

你在 A 群的机器人上绑过营地ID，被拉到 B 群（另一个 bot 主人搭的实例）时，不用重新绑定就能直接查战绩。**默认不共享**，要自己发指令开：

```
#开启营地ID共享   #开启营地共享 #打开营地共享    把营地ID传上去
#关闭营地ID共享   #取消营地共享                取消共享，之前传上去的也会删掉
#营地ID共享状态   #营地共享状态                看看自己开没开、共享了哪些号
#同步营地ID共享                               立刻推一次，之后改绑定不会自动跟着走
```

单独看这块的帮助图：`#营地ID共享帮助`。

上传的是「QQ 号的加盐哈希 → 营地ID」，**不上传登录态、不上传战绩，一个字的凭证都不上传**。共享库由主人统一提供，**地址和令牌进群 `972915804` 找主人要**，三步接上：`#营地共享库地址 <地址>` → `#营地共享库令牌 <令牌>` → `#接入营地共享库`；本机要有可用的全局账号才查得动，共享过来的号在本机查过一次后就会记下来（**按需落地**，没人查过不会主动同步）。

### 开黑组队（可选的跨机器人功能）

一个群凑不齐五个人是常态。接入同一个服务端的机器人**共享一个房间池**：你在 A 群发起，十几个群同时看得到，B 群的人就能补上那个缺的辅助。

```
#发起开黑 打野 缺辅助 3排 20:30    #开黑招人    发起一个房，服务端分配两位编号
#加入开黑 12 辅助                 #加开黑      加进 12 号房，打辅助
#开黑列表                        #开黑房间     出一张图：谁在招人、每个位置谁占了、还缺哪个
#退出开黑 [编号]                              把位置让给别人
#取消开黑                                     取消自己发起的那个房
#开启开黑广播 / #关闭开黑广播                   本群要不要收开黑播报（群管理发，默认关）
```

**参数顺序随便写**：`#发起开黑 3排 20:30 缺辅助发育 打野` 和上面那条等价。各段都能用口语：

| 写什么 | 都认哪些写法 |
| --- | --- |
| 分路 | 对抗路 / 对抗 / 上单 / 上，中路 / 中单 / 法师 / 中，打野 / 野 / 刺客，发育路 / 发育 / 下路 / 射手 / adc，辅助 / 辅 / 奶妈，都行 / 随便。**第一个是自己玩的，后面写的都算缺的位置**（`#发起开黑 发育 辅助 打野 3排` = 你玩发育、缺辅助和打野） |
| 缺的分路 | `缺辅助`、`缺辅助发育`（连写多个）、`差中辅` |
| 几排 | `3排` / `三排` / `3人` / `3` |
| 约定时间 | `20:30` / `20点半` / `8点`（下午说就是晚上 8 点） / `半小时后` / `1小时后`；不写 = 30 分钟后 |
| 游戏房间号 | `房间号123456` / `房号 123456` / 直接写 `123456`。填了会显示在播报图的约定时间边上，别的群的人照着进房；不填就走「QQ 联系」（加进来之后私聊告诉你发起人的 QQ） |

**到约定时间房间自动结束**，从列表里消失，最长 12 小时。编号是所有机器人共用的，**每天零点（北京时间）从 10 重新排**。

两点和隐私有关：

- 群里的播报**只有昵称和段位，不出现任何 QQ 号和营地ID**。
- 加入成功后，双方的机器人**各自私聊**把对方的联系方式发过去。所以要先加机器人好友 —— 私聊发不出去时会把你的占位退掉，并告诉你重发哪条指令。

群里只播两条：**有人发起**（这个房在招人）和**人齐了**，而且**只播开了广播的群**（默认一个都没开）。前者发到每个开了广播的群，后者**只发参与过这个房的群**（发起群 + 有人加入的群）并 @ 上参与的人 —— 没参与的群不会知道哪个房满了。

段位和战力是发起/加入时从营地现查的，没绑营地ID 也能用，只是卡片上不显示这两项。

接入方式和观战、营地消息**共用一套**：地址默认已填好，只差一个令牌 —— 机器人主人发 `#营地共享库令牌 <令牌>` 就行（令牌进群 `972915804` 找主人要，观战 / 营地消息 / 开黑共用这一个）。已经接过共享库的机器升级插件就能直接用，不用再配。**播报默认不发到任何群**：要收的群让群管理在群里发 `#开启开黑广播`，或者主人在锅巴「王者插件 → 服务端接入 → 收开黑播报的群」里勾上。
