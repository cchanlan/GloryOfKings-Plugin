## 安装

在**云崽根目录**执行：

```bash
git clone --depth=1 https://gitcode.com/ccxhan/GloryOfKings-Plugin.git ./plugins/GloryOfKings-Plugin/
# GitHub 也行：https://github.com/cchanlan/GloryOfKings-Plugin.git

pnpm install
```

重启 Bot 即可。先 `#绑定营地` 才能查自己的数据。

## 绑定账号

```
#绑定营地 1580886057      营地 ID（营地 App「我的」页可见）
#切换营地 2               多号时切换
#删除营地 2
#营地wx登录               扫码登录，拿到更完整的数据权限
```

大部分查询指令都支持 `@某人`（对方也得绑过）和直接写营地 ID，比如 `#查询战绩 @张三`、`#排位表现 1580886057`。

## 查战绩与表现

| 指令 | 说明 |
| --- | --- |
| `#查询战绩` `#排位战绩` `#巅峰战绩` | 最近 30 场；点开某场看双方十人评分 / 经济 / 出装 / 参团率 / 五维评级 |
| `#王者主页` | 段位、巅峰分、战力、胜率、皮肤数一张图 |
| `#全部主页` | 名下所有账号的主页 |
| `#排位表现` `#赛季表现` | 段位积分、分路、常用英雄、雷达图、上分趋势 |
| `#巅峰表现` | 巅峰赛五维与全分路数据 |
| `#全部赛季表现` `#全部巅峰表现` | 历届赛季汇总 |
| `#对比 @某人` | 两个人的数据对照 |
| `#谁在打游戏` | 群里谁正在上号（营地在线状态） |

## 英雄与皮肤

| 指令 | 说明 |
| --- | --- |
| `#常用英雄` | 本赛季场次 / 胜率 / 战力 / 称号 |
| `#我的英雄` | 全部英雄的生涯累计数据 |
| `#称号墙` | 荣耀称号一览（市级 / 小范围榜） |
| `#皮肤墙` `#全部皮肤` | 按价值倒序出图，可 `#皮肤墙 20` 限制数量 |
| `#缺皮肤` | 还差哪些皮肤 |
| `#英雄梯度` | T0~T3 实时强度，可按段位 / 分路筛 |
| `#英雄攻略 李白` | 出装、铭文、核心装备胜率、克制关系 |
| `#皮肤上新` | 新皮肤日历 |

## 趋势与排行

```
#巅峰分趋势        巅峰分曲线（也叫 #上分趋势）
#段位趋势          排位段位变化
#排位排名 #巅峰排名        群内排行，加「刷新」强制重算
#排位总排名 #巅峰总排名     全部已绑用户
```

## 推送订阅

```
#开启战绩推送 / #关闭战绩推送      打完一局自动发全场详情图
#开启上下线提醒 / #关闭上下线提醒    对方上号 / 下号提醒
#战绩推送状态                   看自己订阅了什么
#开启皮肤上新推送
```

两个开关互相独立。战绩推送只在打完新的一局后触发，不会重复推。

## 战绩报告

```
#日报 #周报 #月报                个人报告
#群日报 #群周报 #群月报            全群汇总（限群管理）
#开启日报推送 / #关闭日报推送       个人订阅（周报、月报同理）
#开启群日报推送                   群订阅
#群报状态
```

报告读的是本地战绩归档，不额外刷营地接口；没打过的时间段不推送。
